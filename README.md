# My Favorite Series: Blue Lock

## About
**Blue Lock** is a *sports anime* about football (soccer). Japan builds a special training facility to create the world's greatest striker.

## Main Characters
1. Yoichi Isagi
2. Michael Kaiser
3. Seishiro Nagi
4. Rin Itoshi

## Why I Like It
- Intense and exciting matches
- Characters who grow stronger every episode
- A unique idea: only one striker can come out on top
